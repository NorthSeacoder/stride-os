# Dashboard Visual Prompts

## Direction

- Product scope: current Stride OS dashboard pages
- Pages: `dashboard`, `okr`, `tasks`, `quadrants`, `review`, `settings`
- Chosen visual direction: `A. Horizontal shell layout`
- Style target: Apple-inspired, brushed aluminum workstation, sharp and restrained, premium productivity software

## Global Art Direction

- Dark graphite application canvas
- Brushed gunmetal and aluminum panel surfaces
- Thin cold-white hairline borders
- Very limited ice-blue accent lighting
- Precise spacing, calm hierarchy, no playful shapes
- Sharp control-room feel, not generic SaaS, not cyberpunk

## Shared Master Prompt

```text
Use case: ui-mockup
Asset type: desktop dashboard product screen
Primary request: a premium productivity operating system interface for <page-name>
Scene/backdrop: graphite black application canvas with brushed aluminum workstation surfaces
Subject: a sharp, Apple-inspired productivity dashboard with precise panel layout
Style/medium: high-fidelity UI mockup, premium product design render
Composition/framing: straight-on desktop app view, wide canvas, left slim sidebar, top status bar, spacious main workspace
Lighting/mood: cool white highlights, restrained ice-blue accent glow, crisp metallic reflections, calm and focused
Color palette: graphite black, gunmetal gray, brushed silver, cold white, minimal ice blue accents
Materials/textures: brushed aluminum panels, matte graphite background, fine hairline borders, subtle glass indicators
Text (verbatim): Chinese interface labels only, minimal readable UI text
Constraints: Apple-like restraint, sharp edges, premium tool-software aesthetic, no generic SaaS look, no purple, no neon overload
Avoid: clutter, soft playful shapes, rounded bubbly cards, cyberpunk noise, marketing landing page style, mobile phone frame, watermark
```
